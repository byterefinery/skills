# Community Extensions

Third-party extensions that work with Oat.

## oat-chips

**Chip/tag component** with dismissible filters, colors, and toggle selection. ~1KB gzipped.

- Repository: https://github.com/someshkar/oat-chips
- Demo: https://oat-chips.somesh.dev

## oat-animate

**Lightweight animation extension** with declarative `ot-animate` triggers (`on-load`, `hover`, `in-view`) and reduced-motion support. ~1KB gzipped.

- Repository: https://github.com/dharmeshgurnani/oat-animate
- Demo: https://oat-animate.dharmeshgurnani.com

## oat-table

**Semantic table enhancement** — sort, filter, and select rows without turning tables into a framework widget.

- Repository: https://github.com/MADEVAL/Oat-Table
- Demo: https://demo.globus.studio/oat-table/

## oat-upload

**Advanced file upload** — dropzone, file previews, validation, removal, and progress for native `<input type="file">`.

- Repository: https://github.com/MADEVAL/Oat-Upload
- Demo: https://demo.globus.studio/oat-upload/
