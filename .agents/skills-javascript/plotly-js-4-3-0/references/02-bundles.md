## Locales

`dist/` ships many `plotly-locale-*.js` files (e.g. `plotly-locale-de-ch.js`; file names are lowercase). Load one after the plotly.js script tag, then set it globally with `Plotly.setPlotConfig({locale: 'de-CH'})` or per plot via the `config` parameter of `newPlot`.

## Custom bundles

From `CUSTOM_BUNDLE.md` — for when no distributed bundle fits:

1. Clone the repo at the tag you want: `git clone --branch v4.3.0 https://github.com/plotly/plotly.js.git` (then `cd plotly.js && npm i`). plotly.js 4.0+ requires Node 22 / npm 10.
2. Build: `npm run custom-bundle` (all traces by default).
   - `--traces scatter,scattergl,scatter3d` — restrict trace types; `scatter` is always included and cannot be removed, but include it explicitly.
   - `--strict` — use strict trace types where possible.
   - `--out myBundleName` — output `dist/plotly-myBundleName.min.js` (or unminified).
   - `--unminified` — skip minification.
