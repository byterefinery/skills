## Installation

```bash
npm install @mui/material@^6.0.0 @emotion/react @emotion/styled
```

- `react` and `react-dom` (^17, ^18, or ^19) are peer dependencies — install them yourself.
- Icons: `npm install @mui/icons-material@^6.0.0`.
- styled-components instead of Emotion: `npm install @mui/material @mui/styled-engine-sc styled-components` and configure the bundler alias for `@mui/styled-engine-sc`. **Do not use styled-components for SSR** — it is not compatible with server-rendered MUI (its babel plugin cannot process MUI's internal `styled()`); use Emotion for SSR projects.
- Companion packages can move to `6.0.0` together with material: `@mui/icons-material`, `@mui/system`, `@mui/lab`, `@mui/material-nextjs`, `@mui/styled-engine-sc`, `@mui/utils`. MUI X packages (`@mui/x-data-grid`, `@mui/x-date-pickers`, ...) do NOT follow MUI versioning — leave them unchanged.

## Global styles

Add to every app:

```html
<meta name="viewport" content="initial-scale=1, width=device-width" />
```

Roboto font (MUI's default; the default typography config only needs weights 300/400/500/700):

```bash
npm install @fontsource/roboto
```

```tsx
import '@fontsource/roboto/300.css';
import '@fontsource/roboto/400.css';
import '@fontsource/roboto/500.css';
import '@fontsource/roboto/700.css';
```

(Or Google Fonts CDN `<link>` in `<head>`.)

`CssBaseline` — normalizes browsers and sets Material defaults (`box-sizing: border-box`, `body` background from `theme.palette.background.default`, `body1` typography on body). Render it once inside `ThemeProvider`:

```tsx
import CssBaseline from '@mui/material/CssBaseline';

<ThemeProvider theme={theme}>
  <CssBaseline />
  <App />
</ThemeProvider>
```

- `ScopedCssBaseline` applies the reset only to its children (use when migrating a site incrementally). Import it before any other MUI component to avoid box-sizing conflicts.
- `<CssBaseline enableColorScheme />` sets the CSS `color-scheme` property from `theme.palette.mode` so native widgets (scrollbars, form controls) follow dark mode.
- Override baseline output via theme: `theme.components.MuiCssBaseline.styleOverrides`.

## ThemeProvider and useTheme

```tsx
import { ThemeProvider, createTheme, useTheme } from '@mui/material/styles';

const theme = createTheme({ palette: { primary: { main: red[500] } } });

function App() {
  return <ThemeProvider theme={theme}>...</ThemeProvider>;
}

function DeepChild() {
  const theme = useTheme(); // reads the nearest ThemeProvider
  return <span>{theme.spacing(2)}</span>;
}
```

- `ThemeProvider` must be an ancestor of everything it themes. Place it at the root.
- Nesting is supported; the inner theme overrides the outer. Pass a function to extend the outer theme: `<ThemeProvider theme={(outerTheme) => extendedTheme}>`.
- `theme` prop accepts an object or a function of the outer theme.

## createTheme

`createTheme(options, ...args) => theme` — fills in all defaults for a partial theme.

```js
import { createTheme } from '@mui/material/styles';
import { green, purple } from '@mui/material/colors';

const theme = createTheme({
  palette: {
    primary: { main: purple[500] },
    secondary: { main: green[500] },
  },
});
```

Rules:

- Only the **first** argument is processed by `createTheme`. To merge two option objects, deep-merge them yourself (`import { deepmerge } from '@mui/utils'`): `createTheme(deepmerge(options1, options2))`.
- `vars` is an autogenerated field for CSS variables — passing it throws.
- `theme.vars` (when `cssVariables: true`) is private-ish; do not name a custom top-level key `vars`.

## Theme tokens

### palette

Default color roles (each with `main`, `light`, `dark`, `contrastText`): `primary`, `secondary`, `error`, `warning`, `info`, `success`, plus `background` (`default`, `paper`), `text` (`primary`, `secondary`), `divider`, `common`.

- Provide a color role with only `main`; `light`, `dark`, `contrastText` are auto-calculated.
- Color shades from `@mui/material/colors` (e.g., `blue[500]`, `red.A400`).
- Custom colors: tokens are NOT auto-calculated — either provide all four tokens (`main`, `light`, `dark`, `contrastText`) or generate them with the theme's `augmentColor` utility (two-step build, since it relies on `tonalOffset`/`contrastThreshold`):

```js
import { createTheme } from '@mui/material/styles';

let theme = createTheme(); // your base customization, incl. tonalOffset/contrastThreshold
theme = createTheme(theme, {
  palette: {
    salmon: theme.palette.augmentColor({ color: { main: '#FF5733' }, name: 'salmon' }),
  },
});
```

- Color utilities exported from `@mui/material/styles`: `alpha`, `emphasize`, `darken`, `lighten`, `getContrastRatio`, `getLuminance`, `hexToRgb`, `rgbToHex`, `hslToRgb`, `decomposeColor`, `recomposeColor`, plus `keyframes`.
- `palette.mode`: `'light'` (default) or `'dark'`. Prefer the `colorSchemes` API (see [02-styling](02-styling.md) and [07-recipes](07-recipes.md)).

### spacing

Base factor is 8px. `theme.spacing(2)` → `'16px'`. Up to 4 args: `theme.spacing(1, 2)` → `'8px 16px'`; mixing strings works: `theme.spacing(1, 'auto')`.

Customize with a number (factor), a function (`(factor) => \`${0.25 * factor}rem\``), or an array (`[0, 4, 8, 16, 32, 64]`).

### breakpoints

Defaults: `xs` 0, `sm` 600px, `md` 900px, `lg` 1200px, `xl` 1536px (min-width, mobile-first).

Helpers (return media-query strings usable anywhere in CSS/`sx`):

- `theme.breakpoints.up(key)` — `[key, ∞)`
- `theme.breakpoints.down(key)` — `[0, key)`
- `theme.breakpoints.only(key)` — `[key, next)`
- `theme.breakpoints.not(key)` — everything except `key`'s band
- `theme.breakpoints.between(start, end)` — `[start, end)`
- `theme.breakpoints.values` — raw widths; `.unit` (default `'px'`), `.step` (default 5)

Custom breakpoints: provide **all** keys you want (partial lists are not merged):

```js
createTheme({ breakpoints: { values: { mobile: 0, tablet: 640, laptop: 1024, desktop: 1200 } } });
```

In TypeScript, augment `BreakpointOverrides` in `@mui/material/styles` to add/remove keys (set old keys `false`, new keys `true`).

### typography

Material type scale: `h1`–`h6`, `subtitle1/2`, `body1/2`, `caption`, `button`. Each is a CSS object (`fontFamily`, `fontSize`, `fontWeight`, `lineHeight`, `letterSpacing`, `color`...), plus `fontFamily`, `htmlFontSize`, `fontSize` (rem base), `fontWeightLight/Regular/Medium/Bold`.

Add or remove variants under `theme.typography`; remove with `h6: null`. For relative font sizes use `rem` (the html root stays 16px by default — `CssBaseline` does not change it).

### shape, shadows, zIndex, transitions, mixins

- `shape.borderRadius` (default 4) — used by `sx borderRadius` (number multiplier) and Paper/Avatar/etc.
- `shadows[0..24]` — elevation scale; `sx boxShadow: 3` maps to `theme.shadows[3]`.
- `zIndex` — mobileStepper 1000, fab 1050, speedDial 1050, appBar 1100, drawer 1200, modal 1300, snackbar 1400, tooltip 1500. Customize the whole scale together, not one value.
- `transitions` — `create(duration, easing, delay)` helper; components build their motion from it. Override globally: `transitions: { create: () => 'none' }` kills all transitions.
- `mixins.toolbar` — height of a `Toolbar` (56px desktop, 48px mobile); use to offset fixed app bars.

## Custom variables

Add any extra key to the theme and use it via `theme.status.danger` in `sx`/`styled`:

```js
const theme = createTheme({ status: { danger: orange[500] } });
```

TypeScript: augment **both** `Theme` and `ThemeOptions` in `@mui/material/styles` (for `sx`-only usage, augment `@mui/system`'s `Theme`):

```tsx
declare module '@mui/material/styles' {
  interface Theme { status: { danger: string } }
  interface ThemeOptions { status?: { danger?: string } }
}
```

## Theme composition and nesting

When one option depends on another, build in steps:

```js
let theme = createTheme({ palette: { primary: { main: '#0052cc' } } });
theme = createTheme(theme, {
  palette: { info: { main: theme.palette.primary.main } },
});
```

`createTheme` deep-merges later args into the result, so passing a finished theme as the first argument works.

## responsiveFontSizes

`responsiveFontSizes(theme, options?) => theme` — scales typography at `sm`/`md`/`lg` breakpoints (options: `breakpoints`, `factor` (default 2), `variants`, `disableAlign`).

```js
let theme = createTheme();
theme = responsiveFontSizes(theme);
```
