# mui-material 6.5.0

## Overview

Material UI v6 is a comprehensive React component library implementing Material Design 2, with default styles generated by Emotion (the default styled engine; swappable to styled-components). Everything renders from a single **theme object**, and component APIs are **composable** (Dialog = Modal + Paper + transition; TextField = FormControl + Input + Label + HelperText).

Packages:

- `@mui/material` — components + styles (this skill)
- `@mui/icons-material` — 2,100+ Material SVG icons as React components
- `@mui/system` — style functions behind the `sx` prop (ships inside `@mui/material`)
- `@mui/material-nextjs` — Emotion cache providers for Next.js SSR
- `@mui/styled-engine-sc` — opt-in styled-components engine

Core concepts:

1. **Theme** — `createTheme({...})` defines palette, typography, spacing, breakpoints, shape, shadows, zIndex, transitions, and per-component overrides. `ThemeProvider` injects it via React context; `useTheme()` reads it.
2. **`sx` prop** — theme-aware style object (superset of CSS) usable on every component for one-off styling.
3. **`styled`** — Emotion's `styled()` utility for reusable, prop-driven styled components.
4. **Component theming** — `theme.components.MuiX.{defaultProps, styleOverrides, variants}` for global per-component customization.

## Usage

### Setup

```bash
npm install @mui/material@^6.0.0 @emotion/react @emotion/styled
# plus, as needed:
npm install @mui/icons-material @mui/material-nextjs
```

Add the viewport meta tag, the Roboto font (weights 300/400/500/700 via `@fontsource/roboto` or Google Fonts), and `CssBaseline` inside `ThemeProvider`:

```tsx
import * as React from 'react';
import CssBaseline from '@mui/material/CssBaseline';
import { ThemeProvider, createTheme } from '@mui/material/styles';

const theme = createTheme({ palette: { primary: { main: '#1976d2' } } });

export default function App() {
  return (
    <ThemeProvider theme={theme}>
      <CssBaseline />
      <main>...</main>
    </ThemeProvider>
  );
}
```

### Choosing a customization approach (narrowest to broadest)

| Scope | Tool |
|---|---|
| One instance | `sx` prop or `className` |
| A nested slot of a component | `& .MuiComponent-slot` selector inside `sx` |
| Reusable styled component | `styled(Component, { shouldForwardProp })` |
| Every instance of a component | `theme.components.MuiX.{defaultProps, styleOverrides, variants}` |
| Global baseline | `CssBaseline` / `GlobalStyles` |

Specificity order: `sx` prop wins over theme `styleOverrides`, which win over default styles. Theme `styleOverrides` beat theme tokens for the same property.

### Key patterns

- **Responsive values** — `{ xs: ..., sm: ..., md: ... }` objects work in `sx`, `Grid2 size`, `Stack spacing`/`direction`. Default breakpoints: `xs` 0, `sm` 600px, `md` 900px, `lg` 1200px, `xl` 1536px (mobile-first, min-width).
- **Dark mode (v6)** — `createTheme({ colorSchemes: { dark: true } })` plus the `useColorScheme()` hook. Style per-mode with `theme.applyStyles('dark', {...})` instead of checking `theme.palette.mode`.
- **Spacing** — `theme.spacing(2)` = `16px` (8px base). `sx={{ p: 2, mt: 1 }}`.
- **Colors** — theme-aware shorthand in `sx`: `color: 'primary.main'`, `bgcolor: 'background.paper'`.
- **Icons** — `import AddIcon from '@mui/icons-material/Add'` (PascalCase). Theme variants append a suffix: `AddOutlined`, `AddRounded`, `AddTwoTone`, `AddSharp`.
- **Polymorphic components** — nearly every component takes `component` to swap the root element (e.g., `Button component={RouterLink} to="/x"`); ref is forwarded to the DOM node.

## Gotchas

- **Grid v2 props are `size`/`offset`, not `xs`/`sm`/`xsOffset`** — v6 stabilized `Grid2` (`import Grid from '@mui/material/Grid2'`) with `size={6}`, `size={{ xs: 12, sm: 6 }}`, `size="grow"` (replaces the old boolean `xs`). Spacing now uses CSS `gap`.
- **Callbacks as *values* in `sx` are deprecated in v6** — pass the callback as the whole value: `sx={(theme) => ({...})}` instead of `sx={{ height: (theme) => theme.spacing(10) }}`.
- **System props are deprecated** — `mt={2}` / `p={1}` / `color={...}` on `Box`, `Stack`, `Typography` etc. will be removed in the next major; use `sx={{ mt: 2 }}`.
- **Never switch styles on `theme.palette.mode`** — use `theme.applyStyles('dark', {...})`. Mode checks cause SSR dark-mode flicker and misbehave with `cssVariables: true`.
- **`colorSchemes` is the v6 color-mode API** — `createTheme({ colorSchemes: { dark: true } })` gives system-preference switching, tab sync, and `useColorScheme()`. If both `colorSchemes` and `palette` are provided, `palette` takes precedence.
- **`useColorScheme().mode` is `undefined` on first render** — guard it or you get hydration mismatches.
- **`vars` is an autogenerated theme field** (CSS variables). Passing `vars` to `createTheme` throws an error.
- **`Button loading` (v6.4+, replaces Lab's `LoadingButton`)** — the value must be `null` or a boolean. `<Button {...(pending && { loading: true })} />` is discouraged (Google Translate crash).
- **`Select` has no `placeholder` prop** — use a `null` value with a `MenuItem`, or use `Autocomplete`. Accessible selects need a label (`labelId` + `InputLabel`, or `<TextField select label="...">`).
- **`slotProps` replaced `*Props`/`componentsProps` props in v6** — e.g., `slotProps.inputLabel`, `slotProps.transition`, `slotProps.heading`, `slotProps.paper`.
- **Fixed `AppBar` covers content below it** — use `position="sticky"`, or render a second empty `<Toolbar />` as spacer (or `theme.mixins.toolbar` in a styled div).
- **Modals on the server** — `createPortal` does not exist server-side, so pass `disablePortal` in SSR contexts; modal content unmounts when closed unless `keepMounted`.
- **`Stack` ignores child margins** by default (margin-collapse-free spacing via CSS selectors); set `MuiStack.defaultProps.useFlexGap: true` (theme) or `useFlexGap` per instance. Row stacks with `white-space: nowrap` children need `minWidth: 0`.
- **`Typography color` is no longer a system prop in v6** — use `sx={{ color: ... }}` (theme color names like `"textSecondary"` still work on the prop).
- **`ListItem button` prop removed in v6** — use the `ListItemButton` component (also `autoFocus`, `disabled`, `selected`).
- **`Pagination` page is 1-based; `TablePagination` page is 0-based.**
- **`useMediaQuery` has no default theme** — pass a string, a `(theme) => ...` callback (requires a provider), or `'(prefers-color-scheme: dark)'` for dark detection. Tests need a `window.matchMedia` polyfill (jsdom lacks it).
- **Icon imports** — path imports (`@mui/icons-material/Add`) are far faster in dev than named imports from the package root; never import deeper than 2 levels (third level is private).
- **State classes have pseudo-class specificity** — override a state with component + state selectors (`.MuiButton-root.Mui-disabled`); never style a bare `.Mui-*` state class globally.
- **`createTheme` only processes the first argument** — to merge two option objects, `deepmerge` them (`@mui/utils`) before the single call.
- **Custom theme keys need TS module augmentation** (`declare module '@mui/material/styles' { interface Theme { ... } }`), and custom breakpoint keys additionally need `BreakpointOverrides`.
- **Disabled buttons set `pointer-events: none`** — so `cursor: not-allowed` never appears on `:disabled`; add a CSS override or wrap the button.
