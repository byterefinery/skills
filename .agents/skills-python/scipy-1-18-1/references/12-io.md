## MATLAB Files (.mat)

### `loadmat(filename, ...)`

Read a MATLAB .mat file (versions 4–7.1). Returns a dict mapping variable names to NumPy arrays.

```python
import scipy.io
data = scipy.io.loadmat('file.mat')
print(data.keys())            # variable names (plus '__header__' etc. by default)
array = data['variable_name']
```

**Key parameters:**
- `appendmat=True` — include MATLAB header info in keys
- `variable_names=None` — read only specified variables
- `struct_as_record=True` — return structs as record arrays
- `squeeze_me=True` — squeeze singleton dimensions

### `savemat(filename, mdict, ...)`

Write a dict of variables to a .mat file.

```python
import numpy as np
import scipy.io

scipy.io.savemat('output.mat', {
    'x': np.linspace(0, 1, 100),
    'y': np.sin(2 * np.pi * 5 * np.linspace(0, 1, 100)),
})
```

**Key parameters:** `format='7'` (standard), `do_compression=False`, `oned_as='row'` (save 1-D arrays as row vectors).

### `whosmat(filename)`

List variables in a .mat file without loading data → list of `(name, shape, type)` tuples.

```python
import scipy.io
for name, shape, dtype in scipy.io.whosmat('file.mat'):
    print(f"{name}: shape={shape}, dtype={dtype}")
```

### Low-level MATLAB I/O (`scipy.io.matlab`)

`matlab.whosmat(file_obj)`, byte-order detection, and low-level MAT-file reader classes.

## Matrix Market Files

Standard format for sparse and dense matrices.

### `mmread(filename)` / `mmwrite(filename, A, field=None, comment=None)` / `mminfo(filename)`

```python
import scipy.io

matrix = scipy.io.mmread('matrix.mtx')          # dense ndarray or sparse array
scipy.io.mmwrite('output.mtx', matrix)          # field: 'real'/'complex'/'integer'/'pattern'
info = scipy.io.mminfo('matrix.mtx')            # (is_complex, is_symmetric, is_pattern, is_square)
```

**Note:** with the spmatrix→sparray migration, the `spmatrix=True` option on the readers (`mmio`, `FFM`, `hb`, `matlab/_mio`) is **deprecated** in 1.18.0 — sparse reads return sparse arrays now.

## NetCDF Files

NetCDF (Network Common Data Form) for classic-format scientific data.

### `netcdf_file(filename, mode='r', ...)`

File object for NetCDF data; `netcdf_variable` is the variable data object.

```python
import numpy as np
import scipy.io

with scipy.io.netcdf_file('data.nc', 'r') as nc:
    data = nc.variables['temperature'][:]   # read all data
    lat = nc.variables['lat'][:]

with scipy.io.netcdf_file('output.nc', 'w', format='CLASSIC') as nc:
    nc.createDimension('x', 100)
    nc.createDimension('y', 50)
    var = nc.createVariable('data', 'f4', ('x', 'y'))
    var[:] = np.random.rand(100, 50)
    var.long_name = 'My Data'
```

**Note:** for newer NetCDF files (64-bit offset, 64-bit data), consider the `netCDF4` Python package.

## Unformatted Fortran Files

### `FortranFile(file, dtype='<f8', ...)`

File object for unformatted sequential Fortran files (with record markers). Exceptions: `FortranEOFError`, `FortranFormattingError`.

```python
import numpy as np
import scipy.io

with scipy.io.FortranFile('output.bin', 'w') as ff:
    ff.write_arrays([np.array([1, 2, 3]), np.array([[1, 2], [3, 4]])])

with scipy.io.FortranFile('input.bin', 'r') as ff:
    arrays = ff.read_vars()
```

Methods: `write_arrays`/`read_vars`, `write_floats`/`read_floats`, `write_ints`/`read_ints`, `write_complexes`/`read_complexes`, `write_records`/`read_records`.

## WAV Sound Files

### `scipy.io.wavfile`

| Function | Description |
|---|---|
| `wavfile.read(filename)` | Read WAV file → `(rate, data)` |
| `wavfile.write(filename, rate, data)` | Write WAV file |

```python
import scipy.io

rate, audio_data = scipy.io.wavfile.read('audio.wav')
print(f"Sample rate: {rate} Hz, Duration: {len(audio_data)/rate:.2f}s")
scipy.io.wavfile.write('output.wav', 44100, audio_data)
```

`WavFileWarning` is raised for certain formats (e.g. unusual bit depths).

## Harwell-Boeing Files

| Function | Description |
|---|---|
| `hb_read(filename)` | Read Harwell-Boeing file → `(data, info_dict)` |
| `hb_write(matrix, filename, ...)` | Write Harwell-Boeing file |

```python
import scipy.io
matrix, info = scipy.io.hb_read('matrix.hb')
```

## ARFF Files (Weka)

ARFF (Attribute Relation File Format) used by the Weka ML tool.

| Function/Class | Description |
|---|---|
| `arff.loadarff(filename)` | Load ARFF file → `(data, meta_info)` (data is a structured NumPy array) |
| `arff.MetaData` | Metadata object for ARFF attributes |
| `ArffError` / `ParseArffError` | Parse errors |

```python
import scipy.io
data, meta = scipy.io.arff.loadarff('dataset.arff')
```

## IDL Save Files

### `readsav(filename)`

Read an IDL (Interactive Data Language) .sav file → dict-like object.

```python
import scipy.io
data = scipy.io.readsav('file.sav')
print(data.variable_name)
```
